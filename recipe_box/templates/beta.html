Before you install

  1. Install Tailscale from Google Play and accept the EPN Tailnet invitation.
  2. Open Tailscale and confirm it is connected.
  3. Download and install the APK. Android may ask you to allow installs from your browser.
  4. Open EPN Recipe Box and choose Sign In or Create Account.

This page and the Recipe Box server are tailnet-only. Please do not redistribute the APK publicly. Updates will use this same download page.
